# 咨询风 scenario（锁死视觉参数）

## 风格 DNA
- Action Title：正文页主标题必须完整结论句，禁“市场分析”式关键词。
- Navy 权威感，颜色少装饰少信息强；标题/正文默认左对齐。
- 数据页必须带 Source；结构图优先于卡片堆叠。
- 无衬线：Arial + 中文黑体。留白 25–40%，但内容要承担判断与论据。

## 字体
`Arial, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`

## 字号梯度（px）
| 角色 | px | 字重 |
|---|---|---|
| 封面主标 | 60–96 | bold |
| KPI 大数 | 72–120 | bold |
| 页标题 Action Title | 32–40 | bold |
| 副标/卡片小标 | 24–30 | bold |
| 正文 | 18–22 | regular |
| 数据标签 | 16–18 | regular |
| Source/页码 | 14–16 | regular |

## 各版式最低信息量
| 版式 | 下限 |
|---|---|
| cover | 主标+副标+机构+时间，整体≥20字 |
| toc | 3–8 条，每条含编号+名称+摘要，总字数≥80 |
| content（卡片组） | 每卡≥40字，3卡≥120字 |
| content（单主题） | 正文≥120字，主视觉≥30% |
| chart | 主图≥50% 面积，洞察 50–90 字，必须 Source |
| section | 巨字编号+标题+英文副标，≥14字 |

省略页脚：cover / toc / section / closing。
