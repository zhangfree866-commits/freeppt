# 逐单元图形化手册（去 AI 味的唯一有效方法）

> **问题定义**：AI 做的 PPT 之所以"一眼假"，不是因为配色丑或排版乱，而是因为——**每一页都是"标题 + 三段文字"**。文字换了位置，但没换**形态**。读者看到的是 Word 分页，不是 PPT。
> **解法**：每写一个内容单元（一个概念 / 一个模型 / 一条原则），先回答一个问题：**「这个概念天然长什么样？」**，然后照那个形态画。
> **证据**：11 份样本实测。思维模型 30 种那份在被告知"不要流水账"后，把 90 页每页都配了图形，**30 个模型配了 30 种不同图形**，无一复用。这不是模板，是逐个追问出来的。

---

## 1. 核心方法：一个问题 + 三个追问

### 主问题
> **这个概念天然长什么样？**

不要问"用什么版式"，要问"这个概念的形状是什么"。形状对了，版式自然对。

### 三个追问（问不出来时的破局法）

| 追问 | 想什么 | 典型产出 |
|---|---|---|
| **它在空间上有方向吗？** | 上/下、左/右、内/外、中心/边缘 | 金字塔、漏斗、台阶、同心圆、嵌套框 |
| **它在时间上有顺序吗？** | 几个阶段、循环还是不循环、有无回路 | 时间轴、chevron 链、循环箭头、S 曲线 |
| **它在数量上有对比吗？** | 谁多谁少、谁先谁后、有没有临界点 | 柱状降序、区间带、四象限、散点 |

三个都问不出来 → 它可能不是"概念"，而是"一段说明"。那就把它降级为**某张图的旁注**，不要单独占一页。

### 反模式（必须避免的四种"伪图形化"）

| 伪图形化 | 特征 | 为什么不行 |
|---|---|---|
| 卡片里塞三段话 | 3 个圆角卡各装 80 字 | 卡片只是换个容器的文字，形态没变 |
| 图标 + 标题 + 正文 | 每卡一个 icon | 图标是装饰，不承担结构信息 |
| 加个色块当背景 | 底色变了，内容还是文字 | 只是"贴了张壁纸" |
| 把要点改成竖排 | 文字方向变了 | 阅读更累，信息结构没变 |

**判别标准（一句话）**：把这张图里的**所有文字删掉**，剩下的形状还能不能表达这个概念的逻辑？
- 能 → 真图形化。
- 不能 → 只是"文字排版"，回去重想。

### 信息图化密度标尺（顶级咨询 7 份模板实测，2026-11-09 补充）

> 出处：J.P.Morgan(169页) / 埃森哲(401) / 麦肯锡 BA(128) / 麦肯锡顾问(241) / 贝恩(63) / Market Analysis(310) / **西门子 B2B 真实交付(92)**。叶子形状口径（group 已展开、不重复计数）。

"真图形化"之后的下一问：**逻辑画满了吗？** 顶级交付页不是 3–4 个大卡片就收工，而是把一段逻辑拆成几十个图形单元。标尺（叶子形状/页，按页面角色分档）：

| 页面角色 | 叶子形状目标 | 实测出处 |
|---|---:|---|
| 仪式页（封面 / 章节 / 收尾） | 3–15（airy） | 各本封面 |
| 普通概念 / 观点页 | 10–25 | 咨询观点页 |
| 数据 / 图表页 | 25–50 | JPM、麦肯锡真实图表（非默认 chart） |
| 流程 / 机制 / 组织架构 / 全景信息图 | **40–90** | 西门子并购时间轴 85、贝恩组织架构 84 |

**三条落地规则**
1. **图形数 ≈ 文字框的 1.5–2 倍**：顶级真实页 AUTO_SHAPE + LINE 是主力，不是文本框堆字。每段逻辑先有一个承载形状，文字再叠上去（文字不悬空）。
2. **拆逻辑，不堆装饰**：把"一个流程 / 一组机制 / 一张全景"拆成一个个节点 + 连接线，密度自然上来；密度服务于表达逻辑，不是为数字凑形状。
3. **例外是减法风选题**：语录、随笔、人物叙事类按 §设计倾向保持 airy，不强行堆密度。

**口径警告（别被假数字带偏）**
- 数形状要数**叶子**：工具模板大量用整页 group，递归会重复计数。
- toolkit 页会把十几种图表变体堆在一页（几十个"点击此处输入标题"）供挑选——那是**零件库，不是交付页**，绝不当成单页目标。
- 自检对照：我方《英伟达之道》全本约 13.8 形状/页，普通观点页达标，但数据 / 机制页没向 30–60 档上探——这是后续信息图化的主要空间（原语已齐，差构图时拆够单元）。

## 2. 图形库：20 种可复用原型（全部可用原生形状画出）

每个原型都标注：**Field 语义 → 几何构成 → 坐标要点 → 实测出处**。

### A 类：空间结构型（表达"层级 / 包含 / 方向"）

#### A1 金字塔（层级递进、从基础到顶层）
- **语义**：越往上越少、越重要、越抽象
- **几何**：3–5 个梯形（用 `shape kind=rect` + 宽度递减模拟，或 `oval` 裁切不可用则用等宽递减 rect 层叠）
- **坐标**：底边居中对称，每层高度相等（如 5 层 × 76px = 380px），宽度从 100% 递减到 30%，层间距 6–8px（避免 `GEOMETRY_NEAR_TOUCH`）
- **文字**：层内只放 2–6 字标签，右侧引线拉到旁注区
- **实测**：思维模型 30 种 · 第一性原理页

#### A2 漏斗（筛选、收敛、从多到少）
- **语义**：入口量大，逐层筛掉，底部是精华
- **几何**：3–4 个居中矩形，宽度递减（如 1120 → 940 → 780 → 620），高度相等，**层间不连线**，每层顶部圆角
- **坐标**：全部水平居中；每层内两行字（上行"90% 垃圾"+ 下行"低质、重复、噪音"）
- **实测**：思维模型 30 种 · 史特金定律页（三层：全部信息 → 90% 垃圾 → 10% 精华）
- **坑**：漏斗层内文字多了会溢出到下一层——**每层文字必须 ≤ 18 字**，长解释移到漏斗外的旁注区

#### A3 台阶（逐级抬升、因果递进）
- **语义**：一级一级上去，每级是前一级的结果
- **几何**：N 个等宽矩形，x 递增、y 递减（每级升高 40–60px），形成阶梯
- **坐标**：每级宽度 = 画布宽 / (N + 0.5)，级间无缝但**留 2px 缝**避免近距告警
- **实测**：思维模型 30 种 · 汉隆剃刀页

#### A4 同心嵌套框（能力圈、影响圈、包含关系）
- **语义**：外层包含内层，内层是核心
- **几何**：3 个同心圆角矩形（或嵌套的 `roundrect`），由外到内尺寸递减且**必须真正嵌套**（`_is_ancestor` 关系，不会被判为压盖）
- **坐标**：全部共中心；边长比 ≈ 1 : 0.66 : 0.36
- **文字**：每层标一个短标签，配一个右侧图例说明三层的含义
- **实测**：思维模型 30 种 · 能力圈页（外层"知道不知道"、中层"能做"、内层"真正擅长"）

#### A5 四象限（两个维度交叉分类）
- **语义**：两个独立维度，各分高低，交叉出 4 类
- **几何（极简版，推荐）**：**两条线切格**——一条横线 + 一条竖线，不画填充卡。轴标签放在线两端外侧，4 个格的标签放在格中心
- **几何（增强版）**：两条线 + 4 个淡色填充块（`opacity: 6–10`）+ 每个象限一个角标
- **坐标**：横线 y = 360（画布中线）、竖线 x = 640；格中心 = 象限中心
- **实测**：乔布斯传 · 2×2 产品矩阵页（**纯线，零填充卡**，证明极简版完全成立）；思维模型 30 种 · 艾森豪威尔矩阵页

#### A6 七格矩阵 / 多维格阵（多维并列、组合枚举）
- **语义**：一组等权的维度或选项
- **几何**：M×N 等尺寸 `roundrect`，间距统一
- **坐标**：格宽 = (可用宽 − 间距×(N−1)) / N；间距 20–24px
- **实测**：思维模型 30 种 · SCAMPER 页（七格）；20 判断模型 · 全景地图（4×5 = 20 卡）

### B 类：时间流程型（表达"顺序 / 循环 / 阶段"）

#### B1 编号卡链（并列阶段、有先后但无回路）
- **语义**：N 个阶段顺次推进
- **几何**：N 个等尺寸圆角卡一行排开 + **卡间一条细横线**（穿过所有卡的中线，或只在卡间隙露头）+ 每卡一个编号圆
- **坐标**：卡宽 = (1160 − 间距×(N−1)) / N，间距 28–36px；编号圆居中于卡上部，直径 52–64px
- **配色**：阶段色驱动编号圆（§DESIGN_GRAMMAR §2 语义色）；**末卡可反色**（深底）做收束
- **实测**：经济学十大原理 · p40「四个原理是一条决策链」（4 卡 + 穿线 + 第 4 卡深色反白）

#### B2 chevron 步骤链（紧密递进的工序）
- **语义**：一步接一步，箭头咬合
- **几何**：`shape kind=chevron` 横排，宽度相等，前一个的尖咬进后一个的缺口
- **坐标**：首尾两端用 `arrow` 收口；每个 chevron 内只放 4–6 字
- **实测**：20 判断模型 · 5Why 六段链

#### B3 时间轴（线性时间 + 节点）
- **语义**：一段时间上的若干事件
- **几何**：一条水平 `divider` + N 个 `oval` 节点（**节点压在线上**，需标 `decor:true` 或让线在节点下层）+ 节点上下交替放标签（避免拥挤）
- **坐标**：线 y 固定；节点 x 均分或按时间比例；节点直径 18–28px
- **实测**：GROW · p43「T 有时限」四节点轴（起点实心、中间空心、终点金色实心——**用填充状态表达状态**）

#### B4 循环回路（PDCA、贝叶斯更新、反馈环）
- **语义**：闭合循环，末尾回到开头
- **几何**：4 个节点排成方阵 + 4 条带箭头的边（顺时针）；或 4 个弧形箭头拼成圆环
- **坐标**：方阵四角；箭头用 `line` + 三角（`shape kind=triangle` 旋转，或直接用 `line` 的箭头端）
- **关键点**：**闭环必须有可见的"回"路径**（从第 4 个回到第 1 个的那条边要画出来），否则看起来是流程不是循环
- **实测**：思维模型 30 种 · 贝叶斯四节点循环；PDCA 全书主题结构

#### B5 S 曲线 / 曲线图（增长、回归、临界）
- **语义**：不是直线变化，有拐点
- **几何**：`line` 节点连多个短段模拟曲线（每段 30–50px，6–10 段即可平滑），或 `curvedConnector3`
- **坐标**：只画关键点，不追求数学精确；**必须标出拐点与临界线**（一条竖虚线 + 文字）
- **实测**：思维模型 30 种 · 均值回归 / 帕金森定律页；麦肯锡 · 2 条 curvedConnector3

### C 类：数量对比型（表达"多与少 / 排序 / 占比"）

#### C1 柱状降序 + 明度递减（排序、帕累托、贡献度）
- **语义**：谁是大头，谁可忽略
- **几何**：`shape kind=rect` 柱，高按数值、宽相等，降序左→右
- **配色**：**同一色系明度递减**（深 → 中 → 浅 → 灰），前 2–3 根用深色，尾部用灰——**用颜色直接说"这几个是要攻的"**
- **坐标**：柱宽 = 可用宽 / (N × 1.6)；柱间距 = 柱宽 × 0.5；基线 y 固定；数值标在柱顶上方
- **实测**：PDCA · p31「确认要因」六柱降序（深蓝 → 中蓝 → 浅蓝 → 灰），柱顶标百分比，图下加数据口径注

#### C2 区间带（阈值、黄金区间、40-70 法则）
- **语义**：一条连续轴上的一个关键区间
- **几何**：一条长横带（`rect`）+ 中间一段高亮（不同色或更高 `opacity`）+ 两个阈值刻度竖线
- **坐标**：带高 60–80px；高亮段按比例定位；两侧标"过低 / 行动区 / 过高"
- **实测**：思维模型 30 种 · 40-70 法则页（三段区间带，中间高亮"行动区"）

#### C3 占比条 / 堆叠条（构成比例）
- **语义**：整体的组成部分
- **几何**：一条整宽 `rect` 切成 N 段，宽度按占比
- **坐标**：总宽 1160，高 48–64px；段间 2px 缝（避免相切告警）；标签放段内或引线外拉
- **实测**：经济学十大原理（占比条 + 31 张媒体混用）

#### C4 原生图表（真数据、可编辑）
- **语义**：需要精确数值、需要随数据更新
- **几何**：DSL 里写 `chart:{kind,categories,series}`，**编译为 PowerPoint 原生图表对象**
- **何时用**：数据是真实的、会变的、用户可能要改的
- **何时不用**：数据只是"示意"或"教学演示" → 用 C1/C2 手绘更可控，且在 PPT 里不会因为改数据而变形
- **实测**：麦肯锡 · 雷达图（领导力自评，全书唯一原生图表）；其余 10 份几乎全用手绘形状

### D 类：关系对照型（表达"两个东西的关系"）

#### D1 天平（权衡、取舍、两难）
- **语义**：两端此消彼长
- **几何**：一根横梁（`rect` 细长）+ 一根立柱（`rect`）+ 一个底座（`rect` 宽扁）+ 梁上一个 `oval` 支点 + 两端各一根细吊线 + 两个托盘（`rect` 空心或实心）+ 梁两侧各一个砝码小方块
- **坐标**：立柱居中 x=640，梁 y≈300，底座 y≈470；托盘在梁两端下方；两端高度可略不等以暗示倾斜
- **文字**：左"目标 A"、右"目标 B"、柱下标"此消 → 彼长"
- **实测**：经济学十大原理 · p12「资源有限，选择就是权衡」（**这个原型是全书最出彩的一页**，纯形状，无一个位图）

#### D2 同色双卡对照（两个概念的并列对比）
- **语义**：A vs B，地位对等
- **几何**：两张同尺寸 `roundrect` 并置，**底色不同但同明度**（浅蓝 / 浅米，或浅灰 / 浅绿），每卡顶部一条同色短下划线做标题装饰
- **坐标**：卡宽 = (1160 − 32) / 2 = 564；卡高按内容；下划线宽 60–80px，位于卡内左上标题下方
- **实测**：战略桶 · p20「核心观点 vs 战略启示」；战略规划 · p60「红海 vs 蓝海」

#### D3 左右异质双栏（概念 vs 结论，重量不等）
- **语义**：左边是背景/来由，右边是核心结论，主次分明
- **几何**：左栏浅底卡（可 2 张叠放），右栏一张深底大卡；**深卡内再嵌细描边内框**装核心公式
- **坐标**：左栏宽 460–520，右栏宽 560–620；右卡高度可略高于左卡
- **实测**：GROW · p28（左两张浅蓝卡讲"GROW 从哪来"，右一张深蓝卡讲"绩效 = 潜能 − 干扰"，内嵌细框）

#### D4 引线标注（一张主图 + 多路旁注）
- **语义**：一个主体，多个属性需要说明
- **几何**：中心一个主视觉（图形或原生图）+ N 条 `line` 引线拉到周围 / 一侧的文字块
- **坐标**：引线用 `line` 节点，两端贴住主体边缘与文字块边缘；`dash:true` 更轻
- **注意**：引线会进几何碰撞池，需要时给引线标 `role:"data-marker"` 或确保它不压在可见形状上

### E 类：整页结构型（当内容天然是"表"或"清单"）

#### E1 原生表格整页（应用指南、对照速查）
- **语义**：天然两列（做什么 → 怎么做）
- **几何**：DSL `table:{headers,rows}`，编译为原生表格
- **样式**：表头深色底白字（`#1F5CB4` 级蓝底）+ 行间浅灰斑马纹（`#F7F8FA`）+ 表格线仅保留横线
- **坐标**：整宽 1160，首列 32%、次列 68%；行高自适应
- **实测**：思维模型 30 种 · **30 页全部用这个范式**，表头同色即统一，一点都不单调

#### E2 全景地图页（章节导览、N 个单元的一次性总览）
- **语义**：全书 / 全章的结构一眼看完
- **几何**：左侧 N 条竖色条（每条 = 语义色 + 章名 + 一句话）+ 右侧 N×M 卡片矩阵（卡内只有编号 + 名称），**编号用对应章节色**
- **坐标**：左栏宽 260；色条宽 6px、高 72px、间距 40px；右栏卡片 5 列 × N 行，卡高 60–76px
- **实测**：20 判断模型 · p03「20 个模型全景地图」（4 条竖色条 + 4×5 卡片矩阵，**单页 87 个形状**，全书最密的一页）

#### E3 超级编号页（章节呼吸页）
- **语义**：章节切换，给读者一口气
- **几何**：深底满版 + 一个巨型编号（160–260px）+ 3–5 个细描边文字框层级叠放 + 一句"本章要解决什么问题"
- **坐标**：编号可**超出画布**（`bleed:true`）压过框线，制造张力
- **实测**：战略规划 · p30（墨绿底 + 巨型 `04` 越界 + 四层细框）；PDCA · p05（细线方框装 `01` + 衬线中文大标）

## 4. 一页配一个图形：执行流程（六步）

```
① 提取单元
   这一页只讲一个概念吗？不是 → 拆页（一页一概念，不要合并）

② 追问形态
   "这个概念天然长什么样？" → 查 §3 映射表 → 命中则直接用
   未命中 → 用 §1 三追问（空间/时间/数量）推导 → 查 §2 图形库选原型

③ 画骨架（先不管文字）
   只放形状，坐标对齐，跑 lint 确认零 blocker、无近距/压盖告警
   ★ 此时把文字全遮住，看图能不能表达逻辑（§1 判别标准）

④ 填文字
   形状内 ≤ 6 字标签；解释性文字全部移到旁注区
   先跑 lint 看 TEXT_OVERFLOW，再 render 看图

⑤ 配语义色
   有维度 → 按维度取色（DESIGN_GRAMMAR §2）；无维度 → 单主色 + 明度阶

⑥ 加结论条
   底部一行"所以呢"（一句话结论，16–18px，灰或主题强调色）
   ★ 这行是整个图形化的落点，缺了它图形只是插图
```

**时间分配**：③ 占 60%，④ 占 20%，其他 20%。**骨架不对，填字再漂亮也是白费。**

## 5. 附件框架图原生重绘（我方零经验的工序）

用户给了现成的框架图（波特五力、7S、BCG、商业画布……），三种处理方式，**只有第三种是对的**：

| 处理 | 做法 | 问题 |
|---|---|---|
| 直接贴图 | 把附件图作为 `image` 节点插入 | 带水印、不可编辑、分辨率低、风格与全书不符 |
| 丢弃不用 | 只讲文字，不放图 | 用户会觉得"我说了要这个图你没做" |
| **原生重绘（正确）** | **把图当图纸，用形状重画** | 需要工作量，但结果可编辑、无水印、风格统一 |

**实测**：战略规划 88 页，用户给了 8 张经典框架图，成品自述「8 张附件全部用原生可编辑元素重绘（无水印原图）」。全书 0 张位图、0 个表格，全靠形状。

### 重绘五步法

```
① 拆图
   把附件图看成"形状清单"：几个圆？几个方框？几条箭头？几个文字标签？
   在纸上（或注释里）列出：(形状类型, 相对位置, 相对大小)

② 定坐标系
   原图尺寸 → 1280×720 画布的映射。
   做法：找出原图内容的包围盒，等比缩放到目标区域（如 [100, 160, 1080, 480]），
        算出缩放系数 k = min(目标宽/原宽, 目标高/原高)，所有坐标 ×k + 偏移。

③ 画结构层（先形状后文字）
   圆 → oval；方框 → roundrect（radius 10–14）或 rect；箭头 → line 或 chevron；
   分区底色 → rect + opacity 6–10。
   每画一层跑一次 render，看位置对不对。

④ 填标签
   原图的文字照抄，字号按层级定（主标签 20–24px、副标签 16–18px）。
   ★ 标签放不进形状时，缩小字号 or 引线外拉，不要硬塞（会触发 TEXT_OVERFLOW）。

⑤ 统一风格
   颜色换成当前主题调色板（原图配色一律不用）；
   线宽统一 1.0–1.5pt；圆角统一；字体统一。

⑥ 标注来源
   页脚写"重绘自 XXX"，把"这是二次创作"讲清楚。
```

### 重绘判据
- `inspect` 该页 `picture_count == 0`（一个位图都没有）
- 形状数量在合理区间（简单框架 15–30 个，复杂框架 40–80 个）
- 去掉所有文字后，图形结构仍能被认出是原框架

### 只有一种情况可以贴图
原图是**照片、截图、真实数据可视化**（不是示意图）。此时贴图 + 注明出处，且**必须出血或占满半栏**，不要"小图 + 一圈文字"。

## 6. 去 AI 味检查清单（交付前逐条过）

### 文字层
- [ ] 每页标题是**一句话结论**，不是"第三章 第二节"这类目录式标题
- [ ] 没有"首先/其次/最后""综上所述""值得注意的是"这类套话
- [ ] 没有"赋能/抓手/闭环/生态位"这类空心词（除非内容主题本身就是讲这个）
- [ ] 数字都有来源，或明确标注"教学示意"
- [ ] 段落里没有"我们"开头的空泛主语

### 结构层
- [ ] **任意两页的形状骨架不同**（不是同一套版式换文字）
- [ ] 至少 60% 的内容页有"非文字主体"（图形、表格、图表、时间轴）
- [ ] 每页有一个明确视觉主角，不是三块平均分
- [ ] 相邻页密度有变化（不要全篇一个密度）

### 图形层（§1 判别标准的落地）
- [ ] 随机抽 3 页，遮住全部文字，形状仍能表达该页逻辑
- [ ] 没有"卡片里塞三段话"这类伪图形化
- [ ] 图形内的文字 ≤ 6 字/块，长解释在旁注区
- [ ] 每页底部有"所以呢"结论条

### 一致性层
- [ ] 页眉页脚全书统一（三件套）
- [ ] 语义色贯穿（同维度同色，跨页一致）
- [ ] 字体 ≤ 2 种
- [ ] `outerShdw` 计数 ≈ 0（层次靠明度不靠阴影）

### 机器可查（跑命令）
```bash
python3 engine/cli.py verify deck.json --strict     # 零 error 零 warning 为目标
python3 engine/cli.py inspect out.pptx              # picture_count / shape_kind_totals
python3 engine/cli.py render deck.json out_png/     # 抽 3 页看图
```

**lint 能查的**：重叠、溢出、近距、页码、占位残留、密度扁平、备注覆盖。
**lint 查不了、只能靠人眼的**：骨架是否重复、图形是否承担逻辑、结论是否有洞察。**这两类必须自己过一遍。**

## 7. 三个反面样本（真实踩过的）

### 7.1 纳入了但没排好：漏斗压字
思维模型 30 种的史特金定律页（`models30_p75`）——漏斗三层画对了，但底部"关键洞察 / 典型案例"两块文字**直接压在漏斗旁注区上**，字符互相叠印。
**教训**：漏斗两侧的旁注区必须预留（左右各留 ≥ 200px），漏斗本体宽度不超过画布宽 − 400。

### 7.2 缺字：字体覆盖漏洞
GROW 的 p28「绩效 = 潜能 ⊗ 干扰」——`⊗` 符号在渲染时变成豆腐块（□□）。
**教训**：特殊数学符号（⊗ ⊙ ∑ ≈）在中文字体里经常缺字。**用文字描述替代符号**（"潜能 − 干扰"），或用形状画（一个 `oval` + 两条对角线画 ⊗）。这条已进 `FREEFORM_PLAYBOOK.md` §9 的坑清单。

### 7.3 有图但不算图形化：病历式表格
思维模型 30 种的第一性原理页（`models30_p50`）——整页一张两列表格，"行动建议 / 具体做法"，内容完整但没有形态。
**教训**：表格是**合法的图形化**（E1），但**不能 30 页全是表格**。这本书把 30 个模型的核心页做成 30 张表格，虽然统一，但牺牲了"每个模型配一个专属图形"的机会——这是它唯一没做到位的地方，也是我们的机会点。
