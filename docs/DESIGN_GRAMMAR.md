# 设计语法库（11 份高完成度样本归纳）

> **性质**：这是「一本 deck 长什么样才算到位」的语法书，全部条目来自 11 份 85–115 页成品的实测结构解剖 + 数十页渲染图视觉复核，不是推测。
> **取证源**：会话工作区 `doubao-benchmark/`（`ELEVEN_SAMPLE_BENCHMARK.md` 为最终报告，`render/` 为渲染图）。下文标注「实测」的条目均有 OOXML 计数或渲染图支撑。
> **用法**：先读 §1 选定风格位，再读 §2–§8 取具体语法，最后用 §9 六条铁律做自检。

---

## 1. 风格光谱：先选位，再谈细节（实测）

形状密度是风格最硬的指纹。11 份样本落在 9.8–31.1 形状/页之间，**不存在「统一最优密度」，只有「跟选题匹配的密度」**。

| 风格位 | 形状/页 | roundRect 用量 | 图片 | 字/页 | 适用选题 | 实测样本 |
|---|---|---|---|---|---|---|
| **减法 / 杂志风** | 9–12 | **0**（全书零卡片） | 大量，占文件 90%+ | 200–220 | 人物传记、品牌叙事、观点演讲、人文主题 | 乔布斯传 **9.8**（roundRect=0，图片 4.2MB/15 张） |
| **扁平原生** | 13–19 | 中等（170–330） | 集中仪式页 1–15 张 | 165–260 | 培训课件、方法论手册、读书笔记、课程 | 战略桶 13.6 / GROW 14.2 / 经济学 15.5 / 麦肯锡 15.5 / 战略规划 16.7 / PDCA 18.8 |
| **高密度信息** | 23–31 | 大量（396–554） | 极少（3–19 张） | 305–324 | 模型合集、工具书、速查手册 | 20 判断模型 **31.1** / 思维模型 30 种 23.3 |
| **图标驱动** | 25–30 | 最多（973） | 大量位图 159 | ~218 | 产品手册、功能说明、操作指南 | WorkBuddy 手册 28.9 |

**选位判据（三问）**
1. 内容是**讲一个人 / 一个观点**，还是**讲一套可操作方法**？→ 人/观点走减法，方法走平坦。
2. 读者是**顺着读**还是**跳着查**？→ 顺读走平坦，跳查走高密度（表格、矩阵）。
3. 有没有**必须展示的真实影像**？→ 有 → 减法（图片承担情绪）；没有 → 平坦或高密度（形状承担结构）。

**反例警示**：给人物传记套 30 形状/页的高密度模板 = 廉价信息图；给 30 个模型套 10 形状/页的减法 = 每页空洞。风格位的错误是**结构性的**，靠后期微调救不回来。

## 2. 语义色编码（最核心的语法，实测 5 次重复出现）

**定义**：颜色不是装饰，是**信息维度的一次视觉映射**。同一维度在全篇用同一色，色数 = 内容维度数。

| 样本 | 维度 | 色数与映射 |
|---|---|---|
| PDCA | 四阶段 P/D/C/A | 深靛蓝 / 琥珀 / … 四色贯穿全书 |
| 20 判断模型 | 四篇（看清本质/系统决策/认知升级/行动破局） | 蓝 / 绿 / 橙 / 红；**全景地图左侧四条竖色条 + 20 个卡片编号同色** |
| 战略桶 | 四阶段生命周期 | 初创蓝 / 成长绿 / 成熟橙 / 转型红 |
| 塔克曼（thread） | 五阶段 | 青蓝 / 琥珀 / 青绿 / 金 / 暮紫 |
| 战略规划 | 十篇框架 | 单主色墨绿派生明度阶 |

**三条落地规则**

1. **色数由维度数派生，不写死**。4 个阶段配 4 色，5 个阶段配 5 色。先数维度，再取色。
2. **同色必须贯穿三处**：章节页的色条、内容页的标题/编号、总览页的编号块。实测样本 20 判断模型的地图页做到了这一条——左侧竖色条、右侧卡片编号、章节页色块全同色。
3. **主色克制**：全书 1 个主色 + N 个语义辅色，不用第三类色彩系统。实测 `outerShdw = 0`（11 份全部几乎零外阴影），层次靠**明度差 + 描边**，不靠阴影和多彩。

**渲染图证据**：战略桶 p20「核心观点」浅蓝底卡 +「战略启示」浅米底卡，两卡各配一条同色细下划线——同一个模型的两个维度，用两种底色区分，不靠边框。

## 3. 仪式页用图，内容页用形状（11 份无一例外）

**实测数据**：11 份样本的图片量 1–159 张，绝大多数集中在 **1–19 张**，且位置几乎全部是：封面、章节页、封底、少数关键图文页。**内容页清一色原生形状**。

| 页面类型 | 该用什么 | 不该用什么 |
|---|---|---|
| 封面 | 主视觉大图（出血 + 蒙层）或纯色 + 巨型字 | 形状堆砌 |
| 章节呼吸页 | 深色底 + 超大编号 + 一句话钩子（可配背景图） | 卡片矩阵 |
| 内容页 | 原生形状 / 表格 / 图表 | 位图（除必要实拍） |
| 封底 | 深色 + 金句呼应封面 | 新信息 |

**为什么**：图片给的是**情绪与仪式感**（"这是一本正经的作品"），形状给的是**信息精度**（可编辑、可对齐、不漏字）。把图放内容页 = 把情绪用在需要精度的地方，两头都不占。

**例外通道**：确需实拍（人物、产品、现场）时，图必须**出血或占满半栏**，且配窄文字栏——不要"小图 + 一圈文字"的贴图式排版（实测样本里没有一页这么做）。

## 4. 页眉页脚三件套（整本一致性的锚点，实测 11 份统一）

统一的页眉页脚是"同一本书"最便宜的实现方式。实测所有样本都有，格式高度趋同：

```
[页眉]  eyebrow（小字，全大写或分隔点）          [右] 章节标签 / OVERVIEW
        ─────────────────────────────────────  ← 细横线（1px 级）
[标题]  大字号，一句话结论（不是"第三章"）

        ……内容区……

[页脚]  ─────────────────────────────────────  ← 细横线
[左] Source / 课程整理 / 书名          [右] 20 / 90   ← 页码
```

**实测的三种 eyebrow 写法**（任选一，全书统一）
- `第三章 · 步骤三 · 确认要因`（PDCA：章节 + 步骤 + 小节，最细）
- `PRIORITY · 目标与优先级`（麦肯锡：英文大写 + 中文，最有仪式感）
- `思维模型 · MENTAL MODELS`（思维模型：中英对照）

**页码格式**：`20 / 90`（总数带出）或 `003`（三位补零）或方框 `05`（PDCA 用细线方框把页码住）。**页码必须与实际页序一致**——这条已有 lint 规则 `PAGE_NUMBER` 兜底。

**深色页处理**：页眉竖条与强调色**保持不变**，只把文字色换成白/浅蓝，`on` 值随之改深色。这样深页浅页仍是同一本。

## 5. 封面文字框范式（实测 4 种，选一）

封面是"这本书的封面"，不是"第一页"。实测样本有四种成熟范式：

### 5.1 细描边叠框（麦肯锡 / 乔布斯传 / 战略规划）
**最通用、最有高级感**。文字不是"写在背景上"，而是"每个信息层级住在一个细描边方框里"，框线 1px 级、半透明白/浅色，5 层上下叠放：

```
┌ EXECUTIVE LEADERSHIP PROGRAM ┐   ← ① eyebrow（英文全大写）
  ▬▬                              ← ② 短强调线（金色，唯一暖色）
┌ 麦肯锡领导力行为模型 ┐           ← ③ 中文主标题（最大字号）
└────────────────────┘
┌ The 4 Leadership Behaviors… ┐   ← ④ 英文副标 + 中文副标
└────────────────────┘
┌ 企业一号位 · 高管领导力培训课程 ┐ ← ⑤ 资料属性（课程/作者/出处）
└────────────────────┘
┌ 2026 · 内部培训资料 ┐           ← ⑥ 年份/版本
```

**铁律**：框与框之间**不重叠、不贴边**，垂直间距一致；右半屏留给主视觉图（3D 山、人物肖像、几何体），图可出血到画布边缘。

### 5.2 黑底 + 巨型英文 + 出血肖像（乔布斯传）
`STEVE JOBS`（巨型无衬线，白）+ `乔布斯传`（中文大标）+ 两行说明 + 作者名，四五个细框叠放，右侧黑白肖像**底部裁切出血**。全书配色只有黑、白、苹果蓝点缀。

### 5.3 纯色 + 超大编号 + 细框（战略规划）
墨绿满版底，`PART 04` eyebrow + 中文标题 + 英文副标 + 本章驱动问题框 + 关键概念框，右侧一个**超出画布的巨型 `04` 数字**压过框线（有意越界，靠 `bleed` 实现）。

### 5.4 极简左对齐（PDCA 章节页）
深靛蓝底，左侧一个细线方框装 `01` 超大数字，右侧四层细框：章标（琥珀色）→ 中文大标（衬线）→ 副标一句话 → 本章驱动问题。**用衬线字体做中文大标**，是这个范式的辨识点。

**共同点（必守）**：全部有 eyebrow、全部有细线框或细线分隔、全部有一句"本章要解决什么问题"的钩子、全部不用填充色块。

## 6. 内容页的六种经典构图（实测可直接复用）

### 6.1 左右异质双栏（GROW p28）
左栏浅色底卡（概念/来由/发展史），右栏深色主卡（核心公式/结论）。深卡里再嵌一个**细描边内框**装公式。左右重量不等，视线自然落在深卡。

### 6.2 同色双卡对照（战略桶 p20、战略规划 p60）
两张同尺寸卡左右并置，**底色不同但同明度**（浅蓝 / 浅米，或浅灰 / 浅绿），每卡配一条同色细下划线做标题装饰。用于"两个概念对比"（红海 vs 蓝海、核心观点 vs 战略启示）。

### 6.3 纯线矩阵（乔布斯传 p36）
2×2 产品矩阵，**不画一个填充卡**：两条横线一条竖线切格 + 轴标签 + 格内大字产品名 + 灰字说明。证明"少即是多"在结构表达上完全成立，而且更高级。

### 6.4 编号卡矩阵 / 全景地图（20 判断模型 p03）
左侧 N 条竖色条（章节语义色 + 章名 + 一句话），右侧 N×M 圆角卡矩阵，**卡片编号用对应章节色**，卡内只有编号 + 模型名。底部加一句"使用顺序建议"。

### 6.5 数据图 + 洞察旁注（PDCA p31）
左 55% 放柱状图（**同一色系明度递减**表达排序优先级：深→浅→灰），图下加数据口径注；右 45% 放三到四条判断标准 + 一个**暖色底洞察卡**（浅米底 + 棕橙字，装"二八法则"这类金句）。

### 6.6 原生表格整页（思维模型 30 种 p20）
整页一张原生表格：蓝底白字表头 + 浅灰斑马纹 + 首列窄、次列宽。适合"应用指南"这种天然表格化的内容。**30 页全用这个范式也不单调**，因为表头同色即统一。

## 7. 视觉基因：从素材提取一个可复用的形（实测 2 例）

**定义**：从书封面 / 品牌主视觉里抠出一个**形态特征**，在全篇反复使用。它比配色更能建立"这是同一本书"的识别。

| 样本 | 视觉基因 | 落地方式 |
|---|---|---|
| 思维模型 30 种 | 书封面的**带缺角纸条 / 书签形** | 全书地图页的 5 个编号块都做成带缺角的圆角方块（`01`–`05`），配右上 `OVERVIEW` 小字 |
| 20 判断模型 | 罗盘 / 同心轨道 | 封面与章节页用罗盘位图，内容页回到米白底，**只在仪式页出现** |

**提取方法**（四步）
1. 看素材里最显眼的**几何特征**（缺角？斜切？圆环？竖条？）。
2. 判断它能否用 `rect / roundRect / oval / line` 拼出来（拼不出来就放弃，别硬做）。
3. 定一个**固定尺寸 + 固定位置**（如"每章地图页左侧 5 个 72×72 的块"）。
4. 只用在仪式页 / 导航页，**不要用在内容页**（否则喧宾夺主）。

FreePPT 侧支撑：`engine/cover_style.py` 从封面图提取主色、浅色纸底、主色块位置，派生调色板 + 字体气质 + 母题（`band / vertical-rule / arc / dots / grid`）。母题即"视觉基因"的自动化版本。

## 8. 渐变与阴影：按需，集中仪式页（实测修正）

**这是早期误判过的一条，本轮 OOXML 复核给出准确口径**：

| 样本 | gradFill 数 | 分布 |
|---|---|---|
| 管理的常识 | **56** | 章节页深蓝渐变，真实可编辑 |
| WorkBuddy 手册 | 50 | 仪式页 |
| 麦肯锡领导力 | **49** | 仪式页 |
| 战略桶 | 9 | 仪式页 |
| 20 判断模型 | 7 | 仪式页 |
| GROW / PDCA / 战略规划 / 经济学 / 思维模型 30 种 / 乔布斯传 | **0** | 纯扁平 |

**结论（三条）**
1. **真渐变按需用，不是"不会用"也不是"一律烘焙"**。它集中在封面/章节页/封底，**内容页保持扁平**。
2. FreePPT 的渐变原语（`gradient:{stops,angle}` → 真 OOXML `gradFill`）**能力持平甚至更强**（任意角度、可编辑）。这条已从差距清单移除。
3. **阴影几乎不用**：11 份样本 `outerShdw` 全部为 **0**。层次靠明度差与描边。`shadow: soft/medium` 只作为局部提层手段，不要全篇开。

**alpha 用法（实测）**：`alpha` 出现频次 522–2074 次，主要集中值域：`100000`（不透明，绝大多数）、`6000–15000`（6%–15%，淡底卡/蒙层）、`40000–60000`（40%–60%，次级文字/描边）、`85000–90000`（叠层压色）。**典型毛玻璃卡：白填充 `opacity:8` + 白描边 `border_opacity:20`。**

## 9. 六条铁律（11 份样本无一例外，自检用）

| # | 铁律 | 实测支撑 | FreePPT 对应 |
|---|---|---|---|
| 1 | **100% 演讲者备注覆盖**，页均 70–271 字 | 11/11 样本达成（乔布斯传 71.5 最短，管理的常识 271 最长） | `NOTES_COVERAGE`（阻断）/ `NOTES_THIN`（提示） |
| 2 | **有章节呼吸页**，深底 + 大编号 + 一句话钩子 | 11/11 样本 | `kind:"chapter"` 页 + 长 deck 分章护栏 |
| 3 | **页脚带页码**，全书格式统一 | 11/11 样本 | `footer.page` + `PAGE_NUMBER` lint |
| 4 | **`rect` 是绝对主力**（1094–2550 个），圆角卡是配角 | 11/11 样本 | `shape kind=rect` / `roundrect` |
| 5 | **`outerShdw ≈ 0`**，层次靠明度与描边 | 11/11 样本外阴影为 0 | `shadow` 默认 none |
| 6 | **字体 ≤ 2 种组合**（Noto Sans SC 打底 + 一个对比字体） | 11/11 样本 | 主题 `fonts` 令牌 |

**第 6 条补充**：实测的对比字体选择是"英文字体 + 中文字体"配对（Montserrat + Noto Sans SC）或"衬线 + 无衬线"配对（Noto Serif SC + Noto Sans SC）。**不出现第三体**。

## 11. 一页内容页的设计决策流（实操顺序）

```
1. 这页要讲几个点？
     ├─ 1 个点 → 单一视觉主角（大数字 / 大引文 / 一张图 / 一张表）
     ├─ 2 个点 → §6.1 左右异质双栏 或 §6.2 同色双卡对照
     ├─ 3–4 个点 → §6.4 编号卡矩阵（2×2 / 1×3）
     ├─ 5–8 个点 → §6.6 原生表格 或 步骤链（chevron / 台阶）
     └─ 有天然结构（象限/漏斗/循环/金字塔）→ 照结构画（见 CONTENT_GRAPHICS.md）
2. 这些点之间有语义色维度吗？
     └─ 有 → 按维度取色，标题/编号/色条同色（§2）
3. 需要图吗？
     └─ 只有"这是仪式页"或"必须实拍"时才用（§3）
4. 页眉页脚套三件套（§4）
5. 写完抄一遍禁用清单，逐条对
```

## 12. 两处「不要做」（实测教训）

1. **不要用 `--force` 或 `decor` 标记来"绕开"版面问题**。`decor` 的合法用途是"有意的装饰压盖"（编号圆、图标承载块），不是"我压盖了但我不想改"。
2. **不要把所有页做成同一个密度**。11 份样本的形状/页虽然有均值，但**单页峰值达 31–87**，说明它们在密页与疏页之间有明确节奏（`DENSITY_FLAT` 警告就是为这条设的）。全篇一个密度 = 阅读疲劳。
